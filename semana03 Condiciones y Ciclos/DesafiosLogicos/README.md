## Descripción del programa

Programa desarrollado en Java que presenta un menú interactivo en consola para resolver cinco desafíos lógicos mediante estructuras condicionales y ciclos.

El objetivo es aplicar los conocimientos adquiridos sobre `if`, `else if`, `else`, `switch`, `for`, `while`, `do while`, `break` y `continue`, utilizando validaciones numéricas y de texto.

## Desafíos desarrollados

### 1. Generar una secuencia
Solicita un número inicial, un número final y un incremento. Valida los valores ingresados y genera una secuencia utilizando un ciclo `for`.

### 2. Realizar un conteo regresivo
Solicita un número entre 10 y 50 y realiza un conteo regresivo hasta llegar a cero, mostrando el mensaje «¡Despegue!». Utiliza el ciclo `while`.

### 3. Analizar números
Permite ingresar números enteros hasta introducir cero. El programa calcula:

- Cantidad de números positivos.
- Cantidad de números negativos.
- Suma de los números válidos.
- Cantidad de múltiplos de 5 ignorados.

Utiliza `while`, `break`, `continue`, contadores y acumuladores.

### 4. Dibujar una pirámide
Solicita una altura entre 3 y 10 y genera una pirámide de asteriscos utilizando ciclos `for` anidados.

### 5. Validar palabra secreta
Solicita una palabra hasta ingresar correctamente «Guatemala», sin distinguir mayúsculas, minúsculas ni espacios al inicio o al final.

Utiliza `trim()`, `equalsIgnoreCase()` y `do while`.

### 6. Salir
Finaliza correctamente la ejecución del programa.

## Estructuras utilizadas

| Estructura | Aplicación |
|---|---|
| if, else if, else | Validación de condiciones |
| switch | Selección de opciones |
| for | Secuencia y pirámide |
| while | Conteo regresivo y análisis |
| do while | Menú y palabra secreta |
| break | Finalización de ciclos |
| continue | Omisión de números y entradas inválidas |
| Scanner | Lectura de datos |
