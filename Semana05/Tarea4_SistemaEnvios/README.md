# Sistema de Gestión de Envíos

## Descripción

Aplicación de consola desarrollada en Java que permite registrar envíos nacionales e internacionales y calcular su costo final según el tipo de envío.

El programa utiliza Programación Orientada a Objetos para organizar la información y aplicar diferentes reglas de cálculo.

## Objetivo

Desarrollar una aplicación de consola en Java que permita calcular el costo de diferentes tipos de envíos, aplicando los principales conceptos de Programación Orientada a Objetos.

## Temas aplicados

- Clases y objetos
- Atributos y métodos
- Encapsulamiento
- Constructores
- Herencia
- Sobrecarga de métodos
- Sobrescritura de métodos
- Polimorfismo
- Validación de datos
- Uso de Scanner
