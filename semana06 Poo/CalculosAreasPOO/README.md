# Cálculo de Áreas con POO

## Descripción
Aplicación de consola desarrollada en Java que permite calcular el área de diferentes figuras geométricas utilizando los principios de Programación Orientada a Objetos (POO): abstracción, encapsulamiento, herencia, sobrescritura y polimorfismo.

## Figuras implementadas
- **Círculo:** calcula el área utilizando el radio.
- **Rectángulo:** calcula el área utilizando la base y la altura.
- **Triángulo:** calcula el área utilizando la base y la altura.

## Instrucciones para ejecutar
1. Descargar o clonar el repositorio desde GitHub.
2. Abrir el proyecto en IntelliJ IDEA.
3. Verificar que esté configurado el JDK de Java.
4. Abrir el archivo `Main.java` ubicado en la carpeta `src`.
5. Ejecutar el método `main`.
6. Visualizar en la consola el nombre y el área de cada figura con dos decimales.
